## 口径与限制

1. **价格**：官方 REST bid/ask 是标的买卖价；Token 参考价只乘一次 currentMultiplier。中间价为二者均值，是计算参考，不是成交保证。表中 DEX 参考价由池内价再用对手资产参考价折算 USD。价格计算使用 Decimal/BigInt。
2. **周末**：本轮为周六；quote.generatedAt 是接口生成时间，未提供标的最后成交时间。不得据此显示“实时美股成交价”。历史成交、交易时段和停牌状态分别保留。
3. **USD 估值假设**：USDG 按名义 $1 换算，并未证明其即时兑付/市场价格为 $1。ETH 使用同区块 WETH/USDG 池内现价；该值只用于此次研究估值和输入金额换算，不可用作安全预言机。ETH 参考池为 `0x52e65B17fB6E5BA00Ed806f37Afcd2DaA50271Ca`，参考价约 $2,538.916910。
4. **池余额与深度不同**：V2/V3 的“池估值”用 ERC20 池余额，含未领费用/捐赠；V4 使用官方 ReservesLens 重建活跃池的核心 LP 本金，不含费用或 hook 管理资产；hook 统计另存。PoolManager 全局余额未被当作某池 TVL。
5. **深度**：输入名义金额按上述参考价转换，读官方 Quoter 得到输出；V2 按储备与 0.3% 费率公式计算。执行损耗 = 1 − 输出 / 同池交易前现价理论输出，**含手续费**，不包含 gas。2% 与 $100/$1,000/$10,000 仅为本报告的比较档位，不是协议参数；最大通过档位不是精确深度上限。
6. **零活跃流动性**：这些池保留目录但未进行报价。V4 自定义 hook 即使核心 L 为 0 也可能提供外部流动性，已标为待评估，不能断言不能交易；未完成 TVL/报价的字段为 Unavailable，不伪造为零。
7. **覆盖边界**：全部 194 个官方资产均登记；池发现完整覆盖这里列出的三个 Uniswap 官方部署及快照前事件，不声称覆盖 RH 上所有未知 DEX、私有做市或 UniswapX 场外订单。非官方 Stock/ETH/WETH/USDG 对手资产仅登记池，不估值或推荐兑换。
8. **报价限制**：V3/V4 是只读模拟，未签名、未支付、未检查特定钱包余额/allowance。失败单笔以 300 万 gas 探测记录；失败可能来自 gas、hookData 或合约条件，不等于资产被永久禁止。V4 批量模拟失败另做独立调用。空 hookData 不代表已满足任意 hook 的业务要求。
9. **价格偏离筛选**：阅读版“参考筛选池”要求无 hook、样本双向损耗 ≤2%、池价相对 REST 中间参考偏差 ≤10%；这两个数仅服务本报告排序。休市价差、不同采集时间、池价操纵会影响结果，不能据此自动开启生产资产。
10. **成交量**：underlyingDailyTradingVolume 属于标的市场；mintBurn* 原样保留但接口未明确完整统计窗口，不作 DEX 成交量。链上 24h 字段仅在完整获取该协议重点配对窗口事件时填写；USD 量为快照价重估，不是成交时 USD 精确统计。
本轮 24h 链上成交量仅完成 V2 重点池；V3/V4 的额外全量 Swap 扫描触及响应大小限制，未完成，相关字段为 null。详见 data-gaps.json。
11. **预言机目录缺口**：官方 Chainlink 页面提供集成说明，但本轮未成功取得可核验的主链 feed 地址目录；全部 feedProxy 保持 null。不能把其他链 feed 地址或 REST API 当作已验证的主链预言机。
12. **图标**：采用官方 assets.logoUrl 原值，不用自行猜测的地址路径替代；另登记项目已有本地图标路径。公共 CDN 可访问不等于取得商标/再分发授权。

## 生产接入需要复核的事项

- 资产主键使用 chainId + canonical tokenAddress + UID；symbol 只作显示。保留官方状态、乘数及 pending 变更、oraclePaused、交易能力、数据时间和来源。
