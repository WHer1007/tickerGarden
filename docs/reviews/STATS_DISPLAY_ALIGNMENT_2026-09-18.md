# Stats 展示数据对齐验收

日期：2026-09-18。工作树：TickerGarden-alignment，test 分支。本报告记录本地实现与验收，未部署测试/生产，也未改动线上数据库。

## 完成的行为

- Stats、Explore、代币详情复用 `confirmed-display` 的回执/区块校验和事件入口；Stats 不创建额外 RPC 扫描或报价任务。
- 独立 `stats_display_snapshots` 保存全站展示值，配套独立的事件贡献、分钟桶、市场贡献、质押账户/资产汇总。不是页面请求时遍历所有项目。
- 成交额排除已知内部交易；手续费按交易发生时累计，分配按实际分配事件累计。美元金额由后台用共享 `price_references` 计算，USDG 固定为 1 美元。
- 质押按 `UserStockVault` 的账户/Stock 总分配检查点更新；跨多个 Stock 的同一钱包只计一次。展示使用同一已校验事件窗口，不依赖奖励结算等待期。
- 重组时，与市场展示回滚同一个事务内撤销流量贡献、恢复账户前值、修正市场计数，并重新发布统计快照。重复事件不重复计数。
- 无成交时，后台最多按 60 秒周期推进滚动窗口和共享报价估值；真实事件处理批次会更新统计。无 20 分钟展示等待。
- `GET /v1/stats/display` 一次主键读取，支持 `section=overview|allocations|stocks`；不读取链、不临时聚合、不按快照年龄拒绝返回。
- `GET /v1/stats/events` 复用市场展示的 PostgreSQL 通知连接，只向 Stats 订阅者发送实际变化的区域；普通市场通知不会误触发 Stats 页面。
- 浏览器只格式化已存储金额；按区域合并刷新，150ms 合并事件，保留 60 秒补漏读取。页面隐藏/离开停止订阅与读取，重入恢复；失败保留旧值，晚返回请求不能覆盖新页面数据。
- 页面挂载直接读取 Stats 接口，跳过全局 health/foundation 初始化；保持原有样式、文案、Stock 名称/logo、筛选和输入状态。

## 数据结构与复杂度

新增迁移 `0021_stats_display`。成交/费用通过幂等事件行维护分钟汇总；查询合并完整分钟桶与两个边界片段，保留精确的滚动窗口。Blooms 和资产数量通过数据库增量维护，24h 创建数走创建时间索引，钱包数走正引用索引。费用资产估值仅查询相关代币的薄市场行，不读取 Holder 列表。

批量市场写入与事件桶维护使用 statement 级 transition tables，将一批变化按 deployment/asset 聚合后更新计数，避免每个项目反复写同一个总计行。本地回归发现行级写总计会让 20k 一次导入触发 5 秒 SQL 超时，已改成批量增量并通过原测试门槛，未调高数据库超时。

初始化从已有 canonical/finalized 历史种子开始：历史成交每页 1,000 条、质押账户按最新绝对分配检查点每页 1,000 条；再消费共用展示事件追到最新。无需为初始化另扫 RPC。保留已确认尾部回滚所需数据；最终确认且超过 48 小时的流量行可以清理，24h 聚合和可逆尾部不被提前删除。

- Web 完整测试：587 项通过；TypeScript 通过。
- Web 生产构建：通过；资源预算、代码拆分、图标覆盖、12 个公开入口的预渲染和 SEO 检查通过（本地测试配置禁止索引）。
- Backend 完整检查：生成文件、Vercel 打包预检、接口契约、TypeScript、160 项单元测试通过。
- 本地 PostgreSQL 集成：7 项通过，包含数据库权限/迁移、Explore、confirmed-display 和新增 Stats 专项。
- 新增 Stats 数据库用例覆盖：重复事件、成交与费用口径、账户跨资产去重、USDG 无报价时仍为 1 美元、价格变化只通知相关区域、缺失价格只影响估值、区域 API、过旧快照仍可读、SSE 按受众分流、重组撤销、滚动窗口边界、初始化分页与孤块排除。
- 新增浏览器逻辑测试使用模拟 EventSource/fetch，覆盖 ready/change、事件合并、请求中再次失效、失败保留、导航后的晚响应丢弃及超时响应丢弃。未操控浏览器或真实钱包。

- 10,005 个账户的初始化与重复初始化用例通过，无 10,000 条截断；用例包括两次初始化及数据库准备/清理，总耗时约 7 秒。
