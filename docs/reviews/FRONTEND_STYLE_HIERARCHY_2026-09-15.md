# 前端样式层级调整 · 2026-09-15

范围：`TickerGarden-alignment` 的 `test` 工作树，本地完成，未部署。

- 全局：正文 15px、辅助说明 13px、指标基准 28px；加强辅助文字和状态图标对比。主要表单控件采用 46px 高、10px 圆角；开关、图标按钮和紧凑分页保持自身用途。
- 首页：保留桌面首屏结构和手机按钮尺寸；三步说明放大并增加间距；手机介绍及原则栏收紧。
- Create：配对资产、Bloom 目标、启动费用和交易基础费置于摘要首层，其余设置折叠；说明与社交字段收起；手机提供配置检查跳转。填写无效网址后折叠区域会在校验时自动展开，已输入内容保留。
- Explore：加载、失败和无结果统一到结果状态栏；失败只提供一个重试入口；保留已有卡片。空网格不再撑起大块空面板，板块使用分隔线。
- Stats：刷新、更新时间和状态合并到标题区；成交额和手续费收入位于第一行，其余指标降低视觉权重。
- Claim：奖励周期移到选择区；断开钱包时隐藏空金额与表单；连接后恢复选择与金额区域。
- Stake：保留主区域钱包引导；未连接侧栏弱化，手机收起侧栏。
