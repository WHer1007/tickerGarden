# 数据库存储优化实现与验收（2026-09-20）

范围：配置投影、排名、详情快照、队列保留和 Stats 写入。此报告描述本地代码与本地 PostgreSQL 验证，**不表示测试或生产已经执行迁移**。

## 实现结果

| 问题 | 实现 | 保留的行为 |
| --- | --- | --- |
| 配置每次核验复制全部内容 | `0030_config_sets`：配置内容按摘要去重，配置集合复用，发布记录仅关联集合；只有内容变化才插入新内容 | 每次发布的区块、哈希、revision、generation、算法版本及摘要；历史版本读取、重组失效和重新发布 |
| 配置索引反复携带部署与版本长字段 | 内容和集合使用 bigint 内部键，集合成员分页索引不再重复部署摘要；部署/版本关联只在发布锚点保存 | 外部 revision 与 API 游标不变；不按索引扫描次数盲目删除索引 |
| 新旧市值排名重复生成 | `0032_unified_rankings`：由展示 Worker 唯一生成排名，旧市场分页 API 读同一套排名及快照指标；Pipeline 不再独立生成 | 20 分钟排名周期、旧接口过滤及游标；历史旧排名迁入同一表并标记 legacy，不参与当前排名选择，按原两小时策略到期 |
| 三份详情响应重复保存 | `0031_display_sections`：公共指标/Holder/交易/费用保存一份，1H、12H、1D 图表各一行；仅变更的区段更新 | API 响应结构不变；页面读取仍仅查询数据库；创建就绪判断、重组恢复；后台 CAS 版本防覆盖 |
| 队列正文长期累积 | `0033_queue_retention`：成功的链同步任务、已发送 outbox 和已处理 inbox 正文保留 30 天；无错误成功执行明细保留 90 天 | 任务 ID、去重摘要、operation、fencing 等凭据持续保留；失败/未知类型/资金任务不自动清理 |
| 空块反复写 Stats | Stats 内容变化才更新快照和通知；同步进度、初始化状态与核验时间保存在独立游标中 | 新业务事件、价格变化、滚动窗口产生真实统计变化时仍更新；页面不等待同步 |

队列保留由已有 dispatch 调度驱动，无新增 cron 或连接池。四类清理每次各最多 200 条，正常每小时，积压每分钟；异常保留五分钟重试租约。只自动处理 `chain-log-trigger`、`chain-backfill`、`projection-continuation` 三类成功任务。资金审计、奖励证明、失败任务和 Content 队列不纳入此次删除。

详情重组日志新增紧凑保存形式，恢复兼容已有旧格式；本次没有批量删除既有重组或资金证据。前端及合约无需改动，也未新增页面提示或组件。

## 迁移与发布顺序

1. 测试环境先验证迁移；生产执行前保留数据库恢复点，记录各表行数、尺寸、最新发布锚点和权限。报价历史是否备份仍按已批准的独立策略执行。
2. 暂停会发布配置/详情/排名的旧 Worker 与 Pipeline 写入入口，排空活动任务；安排短维护窗口。`0030` 会持有排他表锁，不能把这一批迁移描述为无停顿上线。
3. 依次执行 `0030_config_sets`、`0031_display_sections`、`0032_unified_rankings`、`0033_queue_retention`，再执行权限更新。
4. 发布匹配的新 Read API、Pipeline 和 Worker，再恢复任务。旧配置写入器会被明确拒绝，避免迁移后重新堆积重复行；旧详情读取代码不可继续运行。
5. 验证配置历史分页、详情各区域、创建就绪、当前排名/旧游标、Stats、队列去重；确认新写入采用新结构，再验收表与索引实际尺寸。

`0030` 事务内搬出非配置记录、重建原表内容，释放配置旧堆和索引空间；非配置记录完整保留。搬回时不重放 Holder 资产派生触发器，避免历史记录影响当前派生状态。配置新表仍不可 UPDATE/DELETE。出错时整次迁移回滚。迁移后不能只回滚应用二进制；需要恢复数据库或编写兼容回迁。

## 验证覆盖

- 真实本地 PostgreSQL：重复核验复用、单配置变更、相同版本冲突、旧版本分页、重组后 generation 变化。
- 已有数据升级：从旧配置全快照与旧详情 JSON 结构迁移，验证历史内容、其他 scope 和创建就绪判断不丢失。
- 详情逐行 xmin 检查：只改 12H 图表不写公共数据和其他图表；只改公共价格不写图表；事务回滚及紧凑重组日志还原。
- 排名：旧 API 分页/过滤/快照指标和过期行为、异常计算回滚、重复生成限制。
- 队列：30/90 天边界、失败/混合消息保护、去重凭据保留、调度节流和失败租约；实际 pipeline 角色与 RLS 验证 Content 数据不被修改。
- Stats：空区块推进游标但不改变快照行 xmin、区块、生成时间；独立检查时间避免重复全量刷新。
