## 验证

- 后端完整测试：生成产物、Vercel 打包、接口契约、类型检查、89 项单元测试通过。
- 数据库集成测试：27 项通过，0 跳过；最终结果见本地 `outputs/backend-integration-complete.log`。后端构建和 `git diff --check` 通过。
- 本金容量：10,002 个账户与 10,002 个有效分配，模拟双 RPC；通过分页发布、已完成工作项回收和发布数量检查。容量测试耗时约 50 秒，不作为真实 RPC SLA。
- HTTP 并发：四种实际路由相同请求仅连接一次；不同用户独立查询；失败请求可重试。
- 本金安全：双 RPC 不一致拒绝发布，旧版本继续可读；续作期间账户和仓位共同保持旧指针；无事件刷新及无市场观察记录的续作通过。
- 本地恢复：独立 PostgreSQL 端口 54337，恢复到空的 `tg_restore_populated` 数据库；核对 18 个迁移摘要及 publications、pointers、projection_records、jobs、job_attempts。
- 归档边界：旧历史被导出；当前版本、重组窗口、死信与待执行任务被排除；未删除源记录。
- Relay 测试及版本验收测试通过，队列健康端点实际返回 schema digest；备份 shell 语法检查通过。
