# Explore / 代币详情页逐项优化

根据 `EXPLORE_DETAIL_AUDIT_2026-09-12.md` 实施。没有修改合约、交易参数或数据库结构；链上业务展示数据仍从后端读取。

## 实施清单

| 报告项 | 本次结果 |
| --- | --- |
| 交易报价与后台快照隔离 | 同一交易上下文保留报价、到期计时器和路由校验缓存；市场/资产/路由/阶段等绑定变更会使其失效。钱包切换、链校验、报价过期及提交前 canonical 校验和模拟仍保留。迟到报价按交易上下文检查，不因无关展示对象更新丢失。 |
| 成交与手续费独立刷新 | Read API `detail?section=activity` 只读取 finalized 成交和手续费，跳过图表、交易量和持有人计算。使用只读 repeatable-read 数据库事务；无 RPC。前端可见时独立每 30 秒检查，摘要仍维持较慢缓存。交易回执后最多 12 次有间隔地核对索引，观察到数据库中的 txHash 后停止。 |
| Explore 冗余统计请求 | 采用报告允许的可见市场补充方案：两组首屏就绪后合并可见 ID，只请求这些市场。补充统计只修改卡片的数值和来源时间，不重置分页、重建图片或再次请求列表。校验市场版本、阶段、资产和时间，拒绝错配结果。 |
| 图片加载链路 | 合并同 URI/来源/网关的在途元数据请求，保留 128 项成功缓存、独立消费者取消及 8 秒共享超时；旧超时结果不能污染缓存。每组前四张图片优先加载，其余懒加载。未另建重复缓存，也未增加链上读取。 |
| 错误与恢复边界 | 移除 Explore direct 构建中通用请求失败后的链上缓存兜底；响应校验失败给出独立提示。失败时保留已显示列表并明确标注上次加载结果；无数据时显示不可用，不伪装为空市场。此前长时间停留修复继续保留。 |
| 首屏 JavaScript | 按当前页面 DOM 标记动态加载详情、用户活动及统计组件；跨路由异步结果有 generation 防护。Explore 不需要的组件不再静态打入首屏。 |

## 选择与限制

- Explore 本轮没有改变后端全市场排序或发布契约；补充的美元估值有独立来源时间，不宣称与分页排序指标来自同一发布。完整的同版本指标发布属于另一种更大实现方案，本轮采用原报告明确允许的可见市场方案。
- 图片仍通过既有可信元数据/内容网关加载；没有增加新数据库图片字段或执行迁移。
- 成交/手续费刷新独立于图表周期与持有人统计。索引核对超过重试上限后不伪造已收录状态，正常活动轮询仍可在后端恢复后获得新数据。
- 构建体积约 658 kB → 606 kB，gzip 约 184 kB → 168 kB；这是构建产物比较，不是浏览器首屏或主线程耗时。

## 验证

- 前端 359 项测试及构建通过。回归覆盖交易上下文、活动请求合并/回执重试/离开页面、元数据超时和迟到结果、可见市场统计更新边界以及既有分页和图表隔离。
- 后端契约测试 9 项、单元测试 47 项通过；完整 backend test 包括生成物、打包和类型检查通过。
- 本地真实 PostgreSQL analytics 集成测试通过，无跳过。覆盖 activity 部分回包、图表/持有人缺省、成交/手续费一致性、no-store 和非法 section 拒绝。
- OpenAPI 添加可选 section 参数并升级到 4.3.0；同步生成客户端与两份对应 source lock。
- 测试后端 activity 接口返回 200、8 条成交及 8 条手续费记录，统计/图表/持有人字段为 null；补充统计返回资产和版本标识。
- 所有部署显式指定 sin1，别名切换前检查真实运行函数区域。

## 浏览器验收边界

本轮重试了默认浏览器和 Chrome。浏览器选择接口曾成功，但创建页面均在 30 秒后超时。没有取得可用页面截图、桌面/移动端网络瀑布或长时间停留的真实浏览器证据，也未提交钱包交易。因此视觉/真实交互验收仍未完成，不能用代码测试替代；本报告没有声称已完成这部分验收。
