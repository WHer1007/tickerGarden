# 后端运行方式与容量优化报告

日期：2026-09-14。范围：减少全量更新/批量写入/查询结果、常驻 Node Worker、数据库区域与连接预算。

**代码与限定范围本地验证完成；远程切换未完成，NOT_PRODUCTION_READY。** 本轮没有部署、修改远程数据库或启用 Holder 周期签名。工作区包含此前改动，未提交。

## 已实现

### 1. 减少写入和查询结果

- 新增 0012 `holder_snapshots_covered`。Holder 基表保留最后变化区块，analytics checkpoint 在同一事务内推进公共覆盖。覆盖与最后变化锚点都必须 canonical/finalized；重组会使视图关闭返回。
- 不再每区块重写全部 Holder 快照。变化余额继续使用已有分批写入；新增 0014 将正余额引用计数、资产分组引用和每市场行数改为语句级聚合。
- Analytics、statistics 和持仓统计仅读取所需字段。协议统计不再返回所有未产生待展示手续费的 Meme 精度映射。
- `/v1/market-statistics` 必须显式提供 1–100 个市场；路由及底层查询均校验，缺失/空列表返回 400，不静默截断。当前前端已按可见市场分批请求。OpenAPI 5.1.0、生成客户端和基线摘要同步。
- 修复前端 Global Holder 校验中遗留的 1,000 市场上限；保留安全整数、去重、分组与排除数量关系校验。

### 2. 常驻 Node Worker

- 复用最新 TypeScript `createChainProcessor`，直接消费 PostgreSQL 持久 jobs。默认每秒检查任务，一条链队列一个活跃消费者，工作连接默认 4、独立控制连接 1。
- 0013 增加数据库执行模式；默认仍为 qstash。切换持有 generation 行锁且要求 job/outbox leases 排空。QStash 与 resident 领取入口互斥，Content 队列不受影响。
- 保留 fencing、原指数退避、最大尝试次数和死信；本地送达的 outbox 保存 `resident:` 标识，不伪造第三方 delivery ID。
- 提供 SIGTERM 排空、健康端点、独占锁、控制连接失效退出、300 秒租约和 240 秒任务预算；systemd 负责重启恢复。控制连接要求直连或 session pooling。
- 提供测试 systemd 模板、环境模板、显式 activate/rollback 命令。没有自动启用服务；旧版消费者必须先全部升级，才可切换。

### 3. 数据库区域与连接预算

- 三个 Vercel 后端配置均显式包含 sin1，既有部署区域门禁保留。
- 新增统一预算计算与服务池配置校验：按实例数 × 每实例连接数汇总，包含控制连接、Relay 数据/源连接及队列连接。超预算在连接前拒绝。
- 提供只读预检：核对数据库实际 max_connections、保留连接、当前连接数、TLS 与 SELECT 往返。远程数据库未使用 TLS 时拒绝。
- 可按实际数据库角色映射生成合并后的 `ALTER ROLE ... CONNECTION LIMIT` SQL；预检不自动执行远程修改。
- 样例预算为总连接 100、保留 20、计划使用 63、余量 17。它是规划值，不是线上实例数量或已强制执行的角色配额。Vercel 扩容/滚动发布重叠必须纳入实际预算。

## 失败保留与复测说明

本轮首次 43,000 条余额重放在持续数分钟后触发 5 秒 SQL 时限，失败发生在 Holder 批量插入内的引用计数维护。保留 `initial-holder-replay-failure.json` 和 `incremental.log`。未调高 SQL 时限；0014 按语句聚合后，同一份保留 ABI 数据重放约 9.46 秒，供应量及增量覆盖验证通过。一次定向取消检查返回空集合，没有取消任何数据库会话。

`capacity.json` 为首次规模夹具和查询测试（0014 修复前），其全部功能断言通过、64 并发 P95 约 634 ms；不能把它描述成最终全部实现的独立性能基准。最终写入结果由 `daily-incremental.json`、`quiet-block.json` 替代；最终读结果见 `daily-read-retest.json` 和双实例复测。0014 之后完整数据库集成重新通过。

浏览器第一次自定义拦截页面未成功获取组件数据，保留 `holder-browser-failure.json`；改用实际本地 Vite 页面后，真实 API/组件验证通过。该截图是组件专项页面，不代表重做了整个站点所有业务流程。

- 仓库运行手册记录 VPS/PostgreSQL 在 Singapore；本次只读 SSH 核查返回 `Permission denied (publickey)`，未取得云实例区域元数据、线上 PostgreSQL 设置或服务状态。
- 因此未应用远程迁移/角色配额，未启用 resident Worker，也未完成线上切换和回滚演练。恢复现有 VPS SSH 访问后，按运行手册完成这些步骤。没有采购、迁移服务器或安装 PgBouncer。
- 本机数据库预检的 RTT 和无 TLS 结果仅适用于 localhost。声明的 Singapore 变量用于校验器测试，不能作为本机或线上区域证据。
- 应用单实例池限制不等于全局连接上限。还需落实真实平台实例/并发限制，或按非 superuser 数据库角色应用汇总 CONNECTION LIMIT。
- 全量市场绑定、部分完整检查点、共享资产/配置事件的大范围观察仍有随规模增长的成本。
- 全局 Holder 为审计展示保留完整排除地址集合：本夹具 64,505 地址，响应约 2.9 MB；后续可做独立分页，不能无标记截断集合。
- 没有验证真实 RPC 配额、跨主机网络、Vercel 冷启动、50k/100k 市场或 24/72 小时连续负载。此前 PostgreSQL 并发 DDL 异常根因仍未独立确认；本轮迁移测试串行执行。
