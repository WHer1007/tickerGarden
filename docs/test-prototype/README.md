# TickerGarden Test Prototype archive

This directory contains the product and architecture documents that predate the canonical TickerGarden V1 implementation.

These files are retained only as historical design and audit evidence. They are not current V1 requirements, are not imported by the build or runtime, and must not be used as deployment inputs. Their internal references to a future V1 describe the successor that is now implemented by the canonical root-level `V1_*.md` documents and the `contracts/src/v1/` codebase.

The original executable prototype was removed from the workspace. Its recoverable removal record is preserved in `TEST_CODE_REMOVAL_RECORD.md`.
