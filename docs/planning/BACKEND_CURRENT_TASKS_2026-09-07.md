## Current product/release boundary

Search, candles/K-lines, statistics, reference prices, trade status, activity, and refresh interfaces have implementations. Remaining real-data, wallet, load, and deployment checks must be recorded as integration or acceptance work rather than “API not implemented.” Event collection, discovery, projection, publication, and financial workers have separate responsibilities; the separation itself is not a gap.

The continuous current release does not require rebuilding the obsolete Root/TWAB/Merkle/legacy seven-day Root product flow. Any compatibility work for that path should remain explicitly labelled as legacy/optional. B18 wallet ownership/private preferences and B19 contribution analysis/appeals remain post-release scope under the existing first-version scope; minimal identity and quota controls needed by D06 are separate.
