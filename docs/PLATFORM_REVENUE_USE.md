# Platform 收益用途

TickerGarden 的交易手续费会按照每个市场的规则分配给 Creator、Staker、Holder 和 Platform。本说明只解释已经归属于 **Platform** 的收益如何使用，不改变协议手续费率，也不改变其他参与者的手续费份额。

Platform 收益按以下比例使用：

| 用途 | 占 Platform 收益 | 说明 |
| --- | ---: | --- |
| 股票发展储备 | 70% | 用于购买真实股票或股票代币，作为 TickerGarden 后续产品与生态发展的长期储备。 |
| Meme 回购销毁 | 20% | 每周从平台市场中评选一个表现最佳的 Meme Token，使用当周这部分 Platform 收益进行回购，并将买入的 Token 销毁。 |
| 平台开销 | 10% | 用于产品开发、技术基础设施、安全、审计、合规和日常运营。 |

## 每周 Meme 评选

TickerGarden 每周评选一个表现最佳且符合资格的 Meme Token。评选会综合市场表现、真实交易活跃度、参与用户、流动性和社区增长等因素，不只依据短期价格涨幅或单一交易量。

当周分配给 Meme 回购的 Platform 收益将用于回购获选 Token，并在回购后销毁。评选结果、回购金额和销毁记录将公开展示。若当周没有符合条件的项目，相应预算将保留至后续周期，不会转作平台日常开销。

## 股票发展储备

分配给股票发展储备的收益可用于购买真实股票或经过审核的股票代币。相关资产由 TickerGarden 项目方持有并用于项目长期发展。

该储备不代表 Meme Token 由股票担保，也不赋予 Meme Token 持有人股票所有权、赎回权或分红权。

## 比例示例

当前 Platform 份额为一笔基础协议手续费的 30%。因此，每产生 100 单位基础协议手续费，其中 30 单位归属于 Platform；这 30 单位再按以下方式使用：

- 21 单位用于股票发展储备；
- 6 单位用于每周 Meme 回购销毁；
- 3 单位用于平台开销。

Creator、Staker 或 Holder 获得的其余份额不参与上述二次分配。
